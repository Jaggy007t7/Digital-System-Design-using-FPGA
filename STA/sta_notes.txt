This is one of the most important topics in FPGA design. I'll explain it the way timing analysis is taught in FPGA design and VLSI courses, using your **148.5 MHz RLE design** as the example.

---

# 1. What is Static Timing Analysis (STA)?

Every register in an FPGA captures data on the clock edge.

For correct operation, the data launched from one register must reach the next register **before the next clock edge**.

For example:

```text
           Clock
             │
             ▼
      ┌────────────┐
      │ Register A │
      └────────────┘
             │
             ▼
      Combinational Logic
      (LUTs / DSP / BRAM)
             │
             ▼
      ┌────────────┐
      │ Register B │
      └────────────┘
```

The timing analyzer checks **every such path** in your design.

# 4. What is Slack?

Slack is simply

[
\boxed{\text{Slack}=\text{Required Time}-\text{Arrival Time}}
]

Positive slack

```
PASS
```

Negative slack

```
FAIL
```

Your report

```
Slack = +1.064 ns
```

means

Your slowest path still finishes **1.064 ns before the deadline**.
