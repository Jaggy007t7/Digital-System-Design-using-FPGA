Creating a Custom Overlay for PYNQ-Z2 Using Vivado and Jupyter Notebook
Complete Step-by-Step Guide

This guide explains how to:

Create FPGA hardware in Vivado
Use buttons and LEDs on the PYNQ-Z2 board
Generate .bit and .hwh files
Upload overlays without JTAG
Program FPGA using Jupyter Notebook
Understand the difference between Bitstream() and Overlay()

Board used:

PYNQ-Z2
1. Install Required Software

Install:

Vivado Design Suite
PYNQ Framework Documentation

Flash the PYNQ image onto an SD card and boot the board.

2. Create Vivado Project

Open Vivado:

3. Create Half Adder Verilog Module

Create file:

half_adder.v

Code:

module half_adder(
    input x,
    input y,
    output sum,
    output carry
);

assign {carry, sum} = x + y;

endmodule
4. Create Top Module

Create file:

top_half_adder.v

Code:

module top_half_adder(
    input btn0,
    input btn1,
    output led0,
    output led1
);

half_adder HA (
    .x(btn0),
    .y(btn1),
    .sum(led0),
    .carry(led1)
);

endmodule

This connects:

buttons → half adder inputs
LEDs → half adder outputs
5. Create XDC Constraints File

Create:

top_half_adder.xdc

Add:

## Buttons
set_property PACKAGE_PIN D19 [get_ports btn0]
set_property IOSTANDARD LVCMOS33 [get_ports btn0]

set_property PACKAGE_PIN D20 [get_ports btn1]
set_property IOSTANDARD LVCMOS33 [get_ports btn1]

## LEDs
set_property PACKAGE_PIN R14 [get_ports led0]
set_property IOSTANDARD LVCMOS33 [get_ports led0]

set_property PACKAGE_PIN P14 [get_ports led1]
set_property IOSTANDARD LVCMOS33 [get_ports led1]

9. Understanding .bit vs .hwh
File	Purpose
.bit	Programs FPGA
.hwh	Hardware metadata for PYNQ
10. Uploading Bitstream Without JTAG

You do NOT need JTAG.

Workflow:

Vivado → Generate .bit → Upload to PYNQ → Program from Python
11. Upload Files to PYNQ

Open Jupyter:

http://<board-ip>:9090

.hwh (if available)

to:

/home/xilinx/jupyter_notebooks/
12. Programming Pure HDL Design

Your current design is:

pure Verilog
direct FPGA pins
no AXI
no Zynq PS

Therefore use:

from pynq import Bitstream

bs = Bitstream("top_half_adder.bit")
bs.download()

This programs FPGA successfully.

Buttons and LEDs start working immediately.

13. Why Overlay() Failed

You got:

RuntimeError: Unable to find metadata for bitstream

Reason:

Overlay() expects a .hwh file
your design does not generate one
14. Difference Between Bitstream and Overlay
Method	Needs .hwh	Used For
Bitstream()	No	Pure HDL FPGA designs
Overlay()	Yes	AXI/PYNQ overlays
15. Creating a Proper PYNQ Overlay

To use:

32. Common Errors
Error
Unable to find metadata for bitstream

Cause:

missing .hwh

Fix:

use Bitstream()
OR create AXI block design
AXI IP Not Accessible

Cause:

AXI not connected properly

Fix:

run connection automation
Bitstream Generation Failure

Cause:

missing clock/reset wiring

Fix:

rerun block automation
